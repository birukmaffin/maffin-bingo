# MAFFIN BINGO
Offline Bingo management system for Android and Windows (English + አማርኛ).

* Run now: open `index.html` (Windows: `start-windows.bat`) or host the folder and install it from Chrome — see `docs/INSTALL.md`.
* `docs/USER_MANUAL.md` · `docs/DATABASE.md` · `docs/INSTALL.md`
* Source: `js/core.js` (card/win/finance logic), `js/app.js` (UI + storage), `js/i18n.js` (translations), `css/style.css`
* Tests: `node tests/core.test.js`
* Installers (`desktop/` Electron, `android/` Capacitor) are provided as build recipes and have NOT been built or tested.

Before charging entry or paying cash prizes, obtain every required Ethiopian license and comply with lottery, gaming, tax and consumer-protection rules.
